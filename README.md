# React CS50

Small standalone HTML pages practicing React basics and hooks.

## About
A handful of single-file HTML exercises using React via CDN (no build step) to practice core concepts and hooks (built 2021-07). Renamed from `React_CS50`.

## Features
- `cs501`, `cs502`, `cs503`: basic React component exercises (e.g. counter with class component)
- `react-hooks-useState`: `useState` example
- `react-hooks-useEffect`: `useEffect` example

## Tech stack
- React 17 (via CDN, `unpkg.com`)
- Babel standalone (in-browser JSX transform)

## Getting started
Each folder is self-contained; open its `index.html` directly in a browser.

## Status
Learning project, not maintained.
